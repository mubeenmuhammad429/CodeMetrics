# CodeMetrics: Smart Code Quality & Plagiarism Inspector

CodeMetrics is an automated academic code inspection platform built to evaluate student coding assignments, enforce blind submission policies, and perform AST-based structural plagiarism detection.

## 🚀 System Architecture & Tech Stack
- **Frontend Portal:** Angular Framework (Dark / Glassmorphic UI)
- **Backend API:** ASP.NET Core Web API (C# / .NET 8)
- **Database:** Microsoft SQL Server
- **Inspection Engine:** Python AST (Abstract Syntax Tree) Parser & Similarity Matcher

## 📁 Repository Structure
- `CodeMetrics.API/` -> ASP.NET Core Web API Backend
- `CodeMetrics.UI/` -> Angular Frontend Web Portal
- `CodeMetrics.Engine/` -> Python Structural Parsing & Plagiarism Engine
